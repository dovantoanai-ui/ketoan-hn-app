🧾 Xuất hóa đơn chiều

Bấm 1️⃣ trước để kéo hóa đơn cần xuất hôm nay vào tab CHIỀU. Mở tab đó kiểm tra thấy đúng rồi mới bấm 2️⃣ để đẩy hóa đơn NHÁP lên meInvoice. Máy văn phòng (đang bật watch-chieu.js) sẽ tự xử lý — cần máy đó đang bật và watcher đang chạy.
Nút 📥 Tải Excel danh sách: tải bảng CHIỀU đang hiện ra file .xlsx về máy (máy nào cũng tải được, không cần máy văn phòng). Nếu vừa sửa dòng nào thì bấm "Lưu chỉnh sửa" trước cho chắc.

🧾 Soát & Đẩy hóa đơn bán hàng → MISA

Chọn ngày → Tải hóa đơn → soát → tick phiếu đúng → Đẩy phiếu đã chọn. Phiếu thiếu giá (đỏ) khoá lại — sửa ở hóa đơn gốc (app giao hàng) rồi bấm Tải lại. Phiếu vào MISA ở trạng thái chưa ghi sổ. Cần máy văn phòng bật (Task "đẩy MISA") và không ai đang mở MISA.
Lọc:
Số CT bắt đầu
Nút 📥 Tạo Excel: chỉ lấy phiếu đang tick → tải file .xlsx chuẩn MISA về máy để anh tự vào MISA → Bán hàng → Thêm → Nhập từ excel (không cần máy văn phòng). Nút 🚀 Đẩy: đêm 01:30 vẫn tự đẩy các ngày chưa lên. Kiểm tra trạng thái lần đẩy gần nhất

🏬 Quản lý cửa hàng

Sửa Tên đơn vị / MST / Địa chỉ ngay trên bảng bên dưới, bấm "💾 Lưu chỉnh sửa" để ghi vào Sheet. Khi cần áp dụng cho máy văn phòng (dùng để xuất hóa đơn), bấm "📤 Xuất file cho máy văn phòng" — máy sẽ tự ghi đè file master, không cần restart watcher.

📝 Ghi chú cửa hàng

Ghi chú nhanh vào từng cửa hàng để xử lý sau. Lưu trên Sheet — mọi máy thấy chung.
